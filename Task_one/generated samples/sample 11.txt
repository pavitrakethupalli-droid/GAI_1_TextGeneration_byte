# Cloud Computing

## 1. Introduction

Cloud computing is a technology that allows users to store data, use software, and access computing resources over the internet instead of depending only on their own computers or mobile devices.

In simple words, cloud computing means using computing services through the internet.

For example, when a student saves an assignment in Google Drive and opens it later on a different computer, the file is stored online rather than only on the student's laptop.

Other examples include Google Photos, Microsoft OneDrive, Gmail, and online coding platforms.

## 3. Difference Between Cloud Storage and Local Storage

Cloud storage and local storage are two common ways of saving digital information.

| Feature       | Cloud Storage                                               | Local Storage                                                 |
| ------------- | ----------------------------------------------------------- | ------------------------------------------------------------- |
| Meaning       | Data is stored on remote servers accessed over a network.   | Data is stored on a device you use or control.                |
| Examples      | Google Drive, OneDrive, Dropbox                             | Laptop SSD, hard drive, USB drive                             |
| Internet      | Usually needed to access or synchronise files.              | Usually not needed for files already stored locally.          |
| Accessibility | Can be accessed from multiple devices with suitable access. | Usually accessed directly from the device or connected drive. |
| Sharing       | Files can easily be shared online.                          | Sharing may require copying files or connecting a device.     |
| Risks         | Online account attacks, service outages, privacy issues.    | Device damage, theft, loss, or drive failure.                 |

Example: If an assignment is saved only on a laptop and the laptop stops working, the student may lose access to it. If the assignment is also backed up to cloud storage, the student may be able to recover it from another device.

Using both cloud and local storage can provide extra protection.

## 4. Three Benefits of Cloud Services for Students

1\. Access from Anywhere

Students can access notes, assignments, and learning materials from home, college, a library, or another location with internet access.

2\. Easy Collaboration

Multiple students can edit shared documents, exchange ideas, and complete group projects. This reduces the need to send many separate file copies.

3\. Saves Device Space and Supports Backup

Files can be stored online, reducing the need to keep every file on a laptop. Cloud synchronisation and backup features can also help recover files if a device is lost or damaged, depending on the service and its settings.

## 5. Security Concerns and Internet Access

Although cloud computing is useful, it has some limitations and risks.

### A. Security Concerns

- Data breaches: Unauthorised people may gain access to stored information.
- Account hacking: Weak passwords or stolen login details can expose personal files.
- Privacy risks: Sensitive academic or personal information may be exposed if sharing permissions are configured incorrectly.
- Service failures: A cloud provider may experience technical problems that temporarily prevent access to files.

Precautions: Use strong, unique passwords, enable two-factor authentication, check sharing permissions, and keep separate backups of important files.

### B. Internet Access Problems

- Cloud services often require a stable internet connection.
- Slow internet may make uploading or downloading large files difficult.
- Students with limited connectivity may struggle to attend online classes or use cloud-based applications.
- Some services provide offline modes, but these must often be enabled in advance and may have limited features.

For example, a student working in an area with poor network coverage may be unable to open an online assignment. Keeping an offline copy of important materials can help overcome this problem.
